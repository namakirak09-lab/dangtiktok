PostFlow Session Bridge

Cài một lần trên Chrome laptop:
1. Giải nén postflow-session-bridge.zip.
2. Mở chrome://extensions
3. Bật Developer mode.
4. Chọn Load unpacked và chọn thư mục đã giải nén.
5. Mở tiktok.com và đăng nhập bình thường trên Chrome.
6. Bấm biểu tượng PostFlow Session Bridge > Xuất phiên TikTok.
7. Quay lại PostFlow > Tài khoản > Nhập phiên Chrome và chọn file JSON vừa xuất.

Sau khi ghép xong, laptop không cần mở để queue cloud chạy.
