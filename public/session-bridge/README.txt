PostFlow Session Bridge v1.1

Cài một lần trên Chrome laptop:
1. Giải nén postflow-session-bridge.zip.
2. Mở chrome://extensions
3. Bật Developer mode.
4. Chọn Load unpacked và chọn thư mục đã giải nén.
5. Mở tiktok.com và đăng nhập bình thường trên Chrome.
6. Refresh trang TikTok một lần sau khi đã đăng nhập.
7. Bấm biểu tượng PostFlow Session Bridge > Xuất phiên TikTok.
8. Quay lại PostFlow > Tài khoản > Nhập phiên Chrome và chọn file JSON v2 vừa xuất.
9. Chờ web tự kiểm tra cloud. Chỉ khi hiện “Sẵn sàng tự đăng” mới coi là ghép xong.

Sau khi ghép và cloud validation pass, laptop không cần mở để queue cloud chạy.
